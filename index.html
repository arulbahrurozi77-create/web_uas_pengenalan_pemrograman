01 — Profil Utama

Tentang Saya

Halo, saya Bahrurozi. Sebagai mahasiswa program studi Informatika di Universitas Islam Negeri Sultan Maulana Hasanuddin Banten, saya memiliki ketertarikan tinggi dalam pengembangan web modern, otomatisasi perangkat lunak, serta perancangan UI/UX Design.

Saya senang mempelajari teknologi baru dan mengimplementasikannya ke dalam proyek nyata. Melalui berbagai pengerjaan aplikasi web dan riset teknologi, saya mengasah keahlian dalam HTML, CSS, JavaScript, React.js, Python, PHP, serta ekosistem backend.

Saya berprinsip pada pemecahan masalah (problem solving) yang terstruktur, mampu bekerja mandiri maupun berkolaborasi dalam tim, serta berkomitmen memberikan solusi digital yang bersih, efisien, dan bermanfaat luas.
